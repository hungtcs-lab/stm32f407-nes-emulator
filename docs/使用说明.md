# 使用说明

STM32_F4VE（STM32F407VET6）+ 3.2 寸 ILI9341 屏上的 NES 模拟器（InfoNES）。

## 编译和烧录

需要 `arm-none-eabi-gcc`、`cmake`、`ninja`、`st-flash`（stlink 工具），调试器用 ST-Link。

```bash
./scripts/fetch-deps.sh                 # 第一次：拉 CMSIS / HAL v1.8.5 / FatFs R0.16 到 third_party/
./flash.sh                              # 编译 + 烧录 NES 固件（默认 Release）
./flash.sh selftest                     # 烧外设自检程序（LCD + SD 测试、LCD 刷新率测试）
./scripts/flash-rom.sh roms/xxx.nes     # 不用 SD，直接把 ROM 烧进板子 Flash；开机会自动拷一份到 SD
./scripts/diag.py                       # 不接串口，用 ST-Link 读板子上的日志、帧率、画质档位
```

`flash.sh` 会先试 probe-rs，不行再用 st-flash（ST-Link 克隆棒固件太老，probe-rs 不认）。

### 编译开关

在 `cmake -S . -B build -DNES_DEFS="A;B"` 里设置，改完再 `./flash.sh`：

| 开关 | 作用 |
|---|---|
| `NES_NO_AUDIO` | 关掉声音，APU 不模拟，每帧省约 1.1ms |
| `NES_NO_INTERLACE` | 性能不够时不用隔行渲染，直接跳帧（画面干净，但降到 30fps） |
| `NES_FRAMESKIP=n` | 固定跳帧，关闭自动降级 |
| `NES_AUTOSTART_MS=n` | 菜单 n 毫秒无操作自动开始（测试用，默认关） |
| `NES_AUTOPLAY="start:150-156,right:300-600"` | 按帧号自动按键（测试用） |
| `NES_INPUT_SCRIPT="b:300-310,a:400-410"` | 按开机时间（10ms 单位）模拟按键，菜单和文件管理也生效（测试用） |
| `NES_CRC_FRAMES="100,300"` | 指定帧的画面 CRC32 写进日志，和 `host/nes_host` 比对（测试用） |
| `NES_BENCH` | 统计第 300~900 帧的平均耗时（测试用） |

## SD 卡目录

```
/NES/ROMS/       ROM（.nes），菜单只列这一层
/NES/SAVE/       存档 .sav
/NES/LAST.TXT    上次玩的游戏
```

- 目录不存在会自动创建；旧结构（ROM、存档直接放在 `/NES/` 下）开机时自动整理
- SD 卡格式：FAT32（exFAT 不支持）。文件名只能显示 ASCII，中文会显示成 `?`

## 按键

| 按键 | 接法 |
|---|---|
| 上 / 下 / 左 / 右 | 外接 PC0 / PC1 / PC2 / PC3 |
| A / B | 外接 PE5 / PE6 |
| SELECT | 板载 KEY0 |
| START | 板载 KEY1 |
| A（备用）| 板载 WK_UP |

外接按键一端接引脚，一端接 GND，不需要电阻（内部上拉）。引脚位置见 `硬件资料.md`。

## 菜单

- 列出 `/NES/ROMS/` 里的游戏，默认选中上次玩的
- **上/下** 或 **SELECT** 切换，**A** 或 **START** 开始，**B** 打开文件管理
- 游戏中 **按住 SELECT + START 1 秒** 退回菜单
- SD 卡读不到时，列表只显示 Flash 存储区里的那个游戏（显示为 `[flash] xxx.nes`）

## 文件管理

菜单里按 **B** 打开，只读，不能删除和改名。

| 按键 | 作用 |
|---|---|
| 上 / 下 | 移动（按住连续滚动） |
| 左 / 右 | 翻页 |
| A | 进入目录；`.nes` 直接运行；其他文件查看内容（文本或十六进制，前 4KB） |
| B | 返回上一级；在根目录按 B 回到游戏菜单 |

- 目录在前、按名字排序；隐藏和系统文件不显示；每个目录最多列 128 项
- 从这里运行的游戏可以放在任何目录，但不会记为"上次玩的"

## 声音

默认开启。输出在 **PA4**，0~3.3V 单端模拟信号，22050Hz，**不能直接接喇叭**：

- 推荐：PAM8403 之类 5V 供电的小功放模块。PA4 → 功放输入，开发板 GND → 功放输入地，功放从开发板 5V 取电
- 临时试听：PA4 → 串 1～10µF 电容 → 耳机一个声道，耳机另一端接 GND。**不要把耳机直接接 PA4**
- PAM8610 这类 12V 大功率功放也能用，但要单独 12V 供电、两边共地、音量从最小开始，喇叭两端都只接功放输出

## 存档

- iNES 头里标了电池的游戏，SRAM 自动存到 `/NES/SAVE/<ROM 名>.sav`
- 开始游戏时读回；游戏中每 30 秒检查一次，有变化才写；退回菜单时立即写
- **关机前最后 30 秒内的进度可能没存上**，想保险就先退回菜单再关机

## ROM 放在哪里

- ≤ 44KB（SMB、2048 这类）：读进 RAM
- 更大的（最大 256KB，比如 Contra 128KB）：写进内部 Flash 扇区 6~7 直接运行；再次选同一个 ROM 时 CRC 一样就不重写 Flash

不支持的 Mapper：5（MMC5）、6、19、85（VRC7）、188、235，选中后会提示 unsupported。

## 画面

- 游戏速度固定在 NTSC 60.1Hz
- CPU 跟不上时自动降级，稳定后自动试着恢复：`全画质` → `隔行渲染` → `隔行 + 跳 1 帧` → `隔行 + 跳 2 帧`
- 隔行渲染时奇偶帧各画一半的扫描线，运动或精灵闪烁时会出现横向细缝
- 屏幕左上角的数字是模拟帧率（每秒 VBlank 次数），不是实际刷新次数
- `./scripts/diag.py` 输出里的 `quality=0/1/2/3` 就是当前档位

## 测试工具

| 脚本 | 用途 |
|---|---|
| `host/`（`make` 后运行 `nes_host`） | 主机上跑同一份模拟器核心，按脚本按键，输出截图（PPM）和每帧 CRC |
| `scripts/nes-bench.sh` | 编译带自动按键的固件、烧录、等跑完读性能数据和 CRC |
| `scripts/sd-soak.sh` | 烧 selftest，反复复位测 SD 稳定性 |
| `scripts/peek.sh <地址或符号> [字节数]` | 用 ST-Link 读内存 |
| `scripts/gen-font.py` | 从 Linux 控制台字体生成 `src/font8x16.h` |
